# Kota Joint Website

A website for Kota Joint, a street food business in Dilopye selling kotas, dagwoods and fish & chips.
Built as Task 3 of the Future Interns Full Stack Web Development internship.

## Live Demo
https://bathabilematshika.github.io/FUTURE_FS_03/

## Features
- Full menu with prices and an Order on WhatsApp button for each item
- Gallery of the food
- About page and opening hours (8am to 9pm)
- Contact form (Formspree) and map
- Mobile-friendly layout and SEO-friendly page titles and descriptions

## Tech Stack
HTML, CSS, JavaScript, Formspree
